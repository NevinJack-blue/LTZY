# LTZY · Liquid Signal Studio

本轮按用户明确要求替换 v2 的克制冷色后台。设计追求丰富的材质、排版和编排动效，但保留可操作的业务界面。

## 视觉与构图

- 画布：冰蓝、银白、青色反光。大标题采用系统无衬线、平衡换行；数值 tabular-nums，代码等宽。
- 材质：金属主视觉与卡片使用方向性反光；玻璃主要用于浮动导航、控制区和信息叠层。正文与表单保留稳定底色，阴影分隔层次而非处处加框。
- 圆角：外壳28/内层20，导航24/内部控件14；间距决定层级，避免把多个不同圆角随意套在一起。
- 官网：非对称玻璃工作室，原创信号雕塑、滚动卡片、线条到扭曲纹理的变化。目录、文档、状态按各自任务使用不同构图。
- 控制台：标准化的独立玻璃导航、真实数据仪表、固定请求详情和可扫读账本；无数据时明确空态，不发明流量趋势。

## 动效分镜

1. 初次打开，原创干涉光带形成空间中心；一组协作光标旋转汇集。
2. 光标按空间、文字、路径、材质分组，依据页面真实边界执行测量、框线和装配，真实元素错开显现。
3. 画布解散、光标离场，交接给实际前端；之后切页采用短时材质入场，不强制重复长动画。
4. 页面以下的内容按滚动进入；首页的一条信号由直线演化为扭曲波形。卡片使用原生滚动，不锁住滚轮。

入场不是网络加载进度。用户可以跳过、Esc退出、重播，也可以选择减少动态效果；操作系统 reduced-motion 自动生效。动画清理必须恢复 inert、取消 RAF/计时器并移除叠层。
