# LTZY 前端性能与主题设计

目标：默认白天亮色、加深蓝青紫信号层次；缩短不必要等待，保持极客开发者内容和真实可操作界面。不能承诺所有老设备都达到固定帧率，测试必须区分桌面浏览器、CPU节流和真机。

## 开销审计与选择

原版入场6.1秒、全屏DPR1.75画布、每帧44条多段曲面与渐变、12光标、DOM滤镜动画叠加大面积玻璃。它既延后可操作时间，也把绘制开销集中在首屏。

新版取消强制等待和全页inert。默认短时非阻塞协作，重播才使用较完整编排。优先用预计算路径与transform/opacity，由浏览器Web Animations执行；不在每帧生成大量渐变和曲线。页面背景改为静态径向渐变，不再有85px全屏模糊图层；玻璃主要保留在少数固定控制层，手机和流畅模式禁用backdrop-filter。

## 昼夜与性能设置

- 默认亮色，不自动把首次访问变成夜晚；用户选择持久保存。
- 小型同步偏好引导脚本在CSS前设置html主题，避免已保存夜间偏好时闪白。
- 自动模式依据saveData、deviceMemory、hardwareConcurrency保守降级；未知设备保持可手动选流畅模式。用户可选完整画质、流畅或自动。
- 减少动态效果独立于主题/画质，并尊重系统设置；切换和路由卸载均清理自身动画。

## 实测结果（2026-11-23）

Edge 157 无头浏览器/CDP，默认入场约1202–1224ms，重播约2501ms，路由约360ms。390px DPR3、4倍CPU节流平均RAF间隔17.68ms，360px DPR3、6倍节流17.93ms；桌面1倍32.41ms、6倍48ms，触发低帧自动降级。RAF间隔不是GPU呈现FPS，移动结果不是物理真机。20个协作光标在流畅模式降至16个；Canvas像素0、页面inert始终false，交互即退出装饰。

官网29项和工作台41项浏览器断言通过，覆盖两主题两视口、持久设置及实际本地测试调用；后端20项回归通过。人工调账与多渠道启停保留，当前单渠道正常完成适配器未在本轮浏览器重造异常夹具；后端相关测试仍覆盖。

## 独立复核补充

默认亮色在操作系统深色设置下仍成立，昼夜、流畅、减少动态偏好刷新后保留。独立会话测得：桌面1200.3ms、平均RAF45.51ms；390px1200.8ms、平均16.91ms；桌面4倍节流1205.9ms、平均57.5ms，录得346/222ms长任务，故不宣称已消除所有低端设备卡顿。快速入场可在153ms时直接导航且不阻塞。手机次级触控目标过小已补44px命中尺寸。

## 验证口径

动画统计是当前会话的实测调度数据，不是网络加载百分比或所有硬件性能承诺。CPU节流只模拟主线程变慢，不等价于低端GPU、真实电池与散热条件。截图检查、功能流程与性能记录应分别报告。
