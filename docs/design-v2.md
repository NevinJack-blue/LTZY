# LTZY 视觉与排版 v2

本轮按用户明确反馈替代先前的暖纸色、橙红强调、衬线大字和地图隐喻。旧设计文档是历史产品推演，不再作为视觉实现标准。

## 方向

冷白画布、石墨色框架、电光蓝交互。题材是可观测的模型 API，而非纸质图鉴。界面使用系统无衬线字体；ID、代码与费用用等宽和等宽数字。

- 官网：非对称超大标题，独立的深色交互式路由工作区。目录、文档、观测分别使用检索、代码阅读和状态监测的布局，不强套一份营销模板。
- 工作台：深色垂直导航，冷白数据面板。请求列表与详情并置，以真实请求数据组织图表和费用；没有样本时显示空态，不填假趋势。
- 颜色：背景 #f7f9fc；正文 #111827；主操作 #2563eb；分隔 #e2e8f0。红色仅表示错误，不用大面积暖黄和橙色。
- 交互：一枚 Key 明文只出现一次；撤销、调账有确认；预算和路由操作直接保存到 SQLite；动画响应操作并尊重减少动态效果设置。

## 工程边界

九页共用同一 Python HTTP 服务、SQLite 和鉴权会话，非静态演示。默认 local/echo 明确是本地确定性测试适配器；真实 HTTPS 模型需提供合法凭据及费率配置。服务只绑定本机地址，单项目单管理员，无支付收款和公网多租户能力。
